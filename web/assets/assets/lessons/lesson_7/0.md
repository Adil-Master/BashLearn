# 🎯 Что он делает?

## Вопрос "Нимә эшләй?"

Чтобы спросить **что делает** человек, используйте вопросительное слово **Нимә эшләй?**

*   **Азат, һин нимә эшләйһең?** — Азат, что ты делаешь?
*   **Ул нимә эшләй?** — Что он делает?

&emsp;

## Основные глаголы

| Башкирский | Русский |
|------------|---------|
| **уҡый** | читает, учится |
| **уйнай** | играет |
| **ултыра** | сидит |
| **ята** | лежит |
| **ала** | берет |
| **ашай** | ест |
| **эсә** | пьет |
| **йөҙә** | плавает |
| **йүгерә** | бегает |
| **ярата** | любит |

&emsp;

**Примеры:**
*   **Миша уҡый.** — Миша читает.
*   **Денис уйнай.** — Денис играет.
*   **Олатай ята.** — Дедушка лежит.
*   **Атай ашай.** — Папа ест.
*   **Кит йөҙә.** — Кит плавает.
*   **Гүзәл йүгерә.** — Гузель бегает.
*   **Өләсәй ултыра.** — Бабушка сидит.
*   **Апай эсә.** — Сестра пьет.
