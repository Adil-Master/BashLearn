# 📚 Винительный падеж

## Аффиксы определенного винительного падежа

| Аффикс | Условие | Пример |
|---------|---------|--------|
| **-ды/-де** | после звонких согласных | **техникумды** — техникум (вин. пад.) |
| **-ты/-те** | после глухих согласных | **китапты** — книгу |
| **-ҙы/-ҙе** | после й, р, и, у, ү, ҙ | **компьютерҙы** — компьютер (вин. пад.) |
| **-ны/-не** | после гласных | **Өфөнө** — Уфу (вин. пад.) |

&emsp;

**Примеры:**
*   **Азат китап уҡый.** — Азат читает книгу.
*   **Азат китапты уҡый.** — Азат читает (эту) книгу.
*   **Азат китаптар уҡый.** — Азат читает книги.
*   **Азат китаптарҙы уҡый.** — Азат читает (эти) книги.

## Винительный падеж местоимений

| Башкирский | Русский |
|------------|---------|
| **Мине** | Меня |
| **Һине** | Тебя |
| **Уны** | Его (её) |
| **Беҙҙе** | Нас |
| **Һеҙҙе** | Вас |
| **Уларҙы** | Их |

&emsp;

**Примеры:**
*   **Кем мине белә?** — Кто меня знает?
*   **Кем һине белә?** — Кто тебя знает?
*   **— Ул һине беләме?** — Он тебя знает?
*   **— Эйе.** — Да.
*   **— Һин мине беләһеңме?** — Ты меня знаешь?
*   **— Юҡ.** — Нет.
*   **— Һин уны беләһеңме?** — Ты его знаешь?
*   **— Эйе, яҡшы беләм.** — Да, хорошо знаю.
