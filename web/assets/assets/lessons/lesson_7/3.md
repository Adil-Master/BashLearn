# 📅 Дни недели

## Названия дней недели

| Башкирский | Русский |
|------------|---------|
| **дүшәмбе** | понедельник |
| **шишәмбе** | вторник |
| **шаршамбы** | среда |
| **кесаҙна** | четверг |
| **йома** | пятница |
| **шәмбе** | суббота |
| **йәкшәмбе** | воскресенье |

&emsp;

**Примеры:**
*   **Азат дүшәмбе уҡый.** — Азат в понедельник читает.
*   **Азамат шишәмбе теннис уйнай.** — Азамат во вторник играет в теннис.
*   **Аня шаршамбы бассейнда йөҙә.** — Аня в среду плавает в бассейне.
*   **Кесаҙна Илһам стадионда йүгерә.** — В четверг Ильгам бегает на стадионе.
*   **Йома Әхәт эшләй.** — В пятницу Ахат работает.
*   **Йәкшәмбе Әлиә китап уҡый.** — В воскресенье Алия читает книгу.

## Временные наречия

| Башкирский | Русский |
|------------|---------|
| **Бөгөн** | Сегодня |
| **Кисә** | Вчера |
| **Иртәгә** | Завтра |

&emsp;

**Примеры:**
*   **Бөгөн дүшәмбе.** — Сегодня понедельник.
*   **Иртәгә шишәмбе.** — Завтра вторник.
*   **Бөгөн шаршамбымы?** — Сегодня среда?
*   **— Эйе.** — Да.
*   **— Бөгөн йәкшәмбеме?** — Сегодня воскресенье?
*   **— Юҡ.** — Нет.
