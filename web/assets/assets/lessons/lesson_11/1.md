# 🌸 Времена года

## Названия времён года

| Башкирский | Русский |
|------------|---------|
| **Яҙ** | Весна |
| **Йәй** | Лето |
| **Көҙ** | Осень |
| **Ҡыш** | Зима |

&emsp;

**Примеры:**
*   **— Ҡасан ҡайта?** — Когда вернётся?
*   **— Яҙ ҡайта.** — Вернётся весной.
*   **— Ҡасан килә?** — Когда придёт?
*   **— Йәй килә.** — Придёт летом.
*   **— Ҡасан китә?** — Когда уедет?
*   **— Көҙ китә.** — Уедет осенью.
*   **— Ҡасан бара?** — Когда поедет?
*   **— Ҡыш бара.** — Поедет зимой.

**Диалог:**
*   **— Әмир, Айгөл ҡасан ҡайта?** — Амир, Айгуль когда вернётся?
*   **— Йәй.** — Летом.
*   **— Әхәт, Нурия ҡасан килә?** — Ахат, Нурия когда придёт?
*   **— Йәй килә.** — Придёт летом.
*   **— Илдар, Гүзәл ҡасан ҡайтты?** — Ильдар, Гузель когда вернулась?
*   **— Көҙ ҡайтты.** — Вернулась осенью.
*   **— Азат, ҡасан ҡайттың?** — Азат, когда ты вернулся?
*   **— Яҙ ҡайттым.** — Вернулся весной.
