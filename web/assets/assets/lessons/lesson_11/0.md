# ⌛ Когда?

## Вопрос "Ҡасан?"

Чтобы спросить **когда** что-то произойдет или произошло, используйте вопросительное слово **Ҡасан?**

*   **Һин ҡасан ҡайтаһың?** — Ты когда вернёшься?
*   **Ул ҡасан ҡайта?** — Он когда вернётся?
*   **Һеҙ ҡасан ҡайтаһығыҙ?** — Вы когда вернётесь?

&emsp;

## Наречия времени

| Башкирский | Русский |
|------------|---------|
| **Иртә** | Рано |
| **Һуң** | Поздно |
| **Хәҙер** | Сейчас, теперь |
| **Әле** | Сейчас, теперь |
| **Әле генә** | Только что |

&emsp;

**Примеры:**
*   **— Азат, ҡасан ҡайтаһың?** — Азат, когда вернёшься?
*   **— Кис.** — Вечером.
*   **— Марат ҡасан ҡайта?** — Марат когда вернётся?
*   **— Быйыл.** — В этом году.
*   **— Улар ҡасан ҡайта?** — Они когда вернутся?
*   **— Бер аҙнанан.** — Через неделю.
*   **— Һин ҡасан ҡайтаһың?** — Ты когда вернёшься?
*   **— Ун көндән.** — Через десять дней.

## Рано и поздно

*   **Иртә ҡайта.** — Возвращается рано.
*   **Һуң ҡайта.** — Возвращается поздно.
*   **Бик һуң ҡайта.** — Возвращается очень поздно.
*   **Атай һуң ҡайта.** — Папа возвращается поздно.
*   **Әсәй иртә ҡайта.** — Мама возвращается рано.
