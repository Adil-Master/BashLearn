# 📧 Современные средства связи

## Виды связи

| Башкирский | Русский |
|------------|---------|
| **Хат** | Письмо |
| **Хат яҙыу** | Писать письмо |
| **Телеграмма** | Телеграмма |
| **Телеграмма ебәреү** | Отправлять телеграмму |
| **Факс** | Факс |
| **Факс ебәреү** | Отправлять факс |
| **Электрон почта** | Электронная почта |
| **Интернет** | Интернет |
| **Интернетҡа инеү** | Входить в интернет |
| **Имейл** | Имейл (электронная почта) |

&emsp;

**Примеры:**
*   **Әсмә хат яҙа.** — Асма пишет письмо.
*   **Әсмә хат яҙған.** — Асма написала письмо.
*   **Әсмә хат яҙасаҡ.** — Асма напишет письмо (обязательно).
*   **Әсмә хат яҙыр.** — Асма напишет письмо (возможно).
*   **Азат интернет аша хат ебәрер.** — Азат отправит письмо через интернет.
*   **Өләсәй телеграмма ебәрәсәк.** — Бабушка отправит телеграмму (обязательно).
*   **Атай факс ебәрәсәк.** — Папа отправит факс (обязательно).

## Вопросы о средствах связи

*   **— Илгиздең имейлы бар.** — У Ильгиза есть имейл.
*   **— Айгиздең имейлы буласаҡ.** — У Айгиза будет имейл.
*   **— Азаттың имейлы булыр.** — У Азата будет имейл (возможно).
*   **— Әсәйенең электрон почтаһы бармы?** — У мамы есть электронная почта?
*   **— Юҡ.** — Нет.
*   **— Һеҙҙә факс бармы?** — У вас есть факс?
*   **— Бар.** — Есть.
*   **— Уның имейлы нисек?** — Какой у него имейл?
*   **— Белмәйем.** — Не знаю.
*   **— Һеҙҙең электрон почтағыҙ нисек?** — Какой у вас электронный адрес?
*   **— Әйтмәйем.** — Не скажу.
