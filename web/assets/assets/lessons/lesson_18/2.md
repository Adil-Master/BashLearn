## Профессии с аффиксом -сы/-се

| Башкирский | Русский |
|------------|---------|
| **Китапханасы** | Библиотекарь |
| **Уҡытыусы** | Учитель |
| **Һатыусы** | Продавец |
| **Яҙыусы** | Писатель |
| **Төҙөүсе** | Строитель |
| **Тегеүсе** | Портной |
| **Нефтсе** | Нефтяник |
| **Компьютерсы** | Компьютерщик |

&emsp;

**Примеры:**
*   **Ул модельер буласаҡ.** — Она будет модельером.
*   **Ирек инженер буласаҡ.** — Ирек будет инженером.
*   **Әлфиә бухгалтер буласаҡ.** — Альфия будет бухгалтером.
*   **Марат менеджер буласаҡ.** — Марат будет менеджером.
*   **Айрат нефтсе буласаҡ.** — Айрат будет нефтяником.
*   **Ғәлиә тегеүсе буласаҡ.** — Галия будет портнихой.
*   **Анна һатыусы буласаҡ.** — Анна будет продавцом.
*   **Ирина уҡытыусы буласаҡ.** — Ирина будет учителем.
*   **Надя төҙөүсе буласаҡ.** — Надя будет строителем.
*   **Игорь яҙыусы буласаҡ.** — Игорь будет писателем.
*   **Люба китапханасы буласаҡ.** — Люба будет библиотекарем.
