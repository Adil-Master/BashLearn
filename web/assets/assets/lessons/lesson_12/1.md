# 🌤️ Погода

## Описание погоды

| Башкирский | Русский |
|------------|---------|
| **Ямғыр** | Дождь |
| **Ямғыр яуа.** | Идёт дождь. |
| **Ҡар** | Снег |
| **Ҡар яуа.** | Идёт снег. |
| **Ҡояш** | Солнце |
| **Ҡояш ҡалҡа.** | Солнце всходит. |
| **Ҡояш байый.** | Солнце заходит. |
| **Ел** | Ветер |
| **Ел сыға.** | Начинается ветер. |

&emsp;

**Примеры:**
*   **Бөгөн ямғыр.** — Сегодня дождь.
*   **Иртәгә ҡар.** — Завтра снег.
*   **Кисә ел.** — Вчера ветер.
*   **Көндөҙ ҡояш.** — Днём солнце.
*   **Бөгөн ямғыр булды.** — Сегодня был дождь.
*   **Төндә ҡар яуҙы.** — Ночью шёл снег.

**Вопросы:**
*   **Бөгөн ямғырмы?** — Сегодня дождь?
*   **Иртән ҡар яуҙымы?** — Утром шёл снег?
*   **Төндә ел булдымы?** — Ночью был ветер?
*   **Көндөҙ ҡояшмы?** — Днём солнце?
