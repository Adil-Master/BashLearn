# 👤 Какой он человек?

## Вопрос "Ул ниндәй кеше?"

Чтобы спросить **какой** человек, используйте вопросительное слово **Ниндәй?**

*   **Азат, һин бәхетле кешеме?** — Азат, ты счастливый человек?
*   **Ул ниндәй кеше?** — Какой он человек?

&emsp;

## Черты характера

| Башкирский | Русский |
|------------|---------|
| **Бәхетле** | Счастливый |
| **Аҡыллы** | Умный |
| **Намыҫлы** | Честный |
| **Эшсән** | Трудолюбивый |
| **Тырыш** | Старательный |
| **Йомарт** | Щедрый |
| **Һаран** | Жадный |
| **Уҫал** | Злой |
| **Ялҡау** | Ленивый |
| **Тыйнаҡ** | Скромный |

&emsp;

## Образование прилагательных

Аффиксы **-лы/-ле** образуют прилагательные от существительных:

*   **бәхет** (счастье) → **бәхетле** (счастливый)
*   **аҡыл** (ум) → **аҡыллы** (умный)
*   **намыҫ** (честь) → **намыҫлы** (честный)
*   **тәм** (вкус) → **тәмле** (вкусный)

&emsp;

**Примеры:**
*   **— Ул йомарт кешеме?** — Он щедрый человек?
*   **— Эйе.** — Да.
*   **— Ул уҫал кешеме?** — Он злой человек?
*   **— Юҡ.** — Нет.
*   **— Ул һаранмы?** — Он жадный?
*   **— Түгел.** — Нет.
*   **— Азат бәхетле кешеме?** — Азат счастливый человек?
*   **— Эйе.** — Да.
*   **— Ул шундай шәп кеше!** — Он такой хороший человек!
