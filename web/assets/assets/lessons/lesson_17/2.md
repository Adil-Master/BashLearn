## Волосы

| Башкирский | Русский |
|------------|---------|
| **Сәс** | Волосы |
| **Ҡара сәс** | Чёрные волосы |
| **Һары сәс** | Светлые волосы |
| **Бөҙрә сәс** | Кудрявые волосы |
| **Сал сәс** | Седые волосы |
| **Ҡыҫҡа сәс** | Короткие волосы |
| **Оҙон сәс** | Длинные волосы |

**С описанием:**
*   **Ҡара сәсле** — черноволосый
*   **Һары сәсле** — светловолосый
*   **Бөҙрә сәсле** — кудрявый
*   **Сал сәсле** — седовласый
*   **Ҡыҫҡа сәсле** — коротковолосый
*   **Оҙон сәсле** — длинноволосый
