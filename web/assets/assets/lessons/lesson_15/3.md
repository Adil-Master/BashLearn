# 📊 Сравнительная степень

## Аффиксы сравнительной степени -раҡ/-рәк

Для сравнения качеств используется аффикс **-раҡ/-рәк**:

| Башкирский | Сравнительная степень | Русский |
|------------|----------------------|---------|
| **йылы** | **йылыраҡ** | теплее |
| **һыуыҡ** | **һыуығыраҡ** | холоднее |
| **ҡыйбат** | **ҡыйбатыраҡ** | дороже |
| **осһоҙ** | **осһоҙораҡ** | дешевле |
| **әҙ** | **әҙерәк** | меньше |
| **күп** | **күберәк** | больше |
| **яҡшы** | **яҡшыраҡ** | лучше |
| **насар** | **насарыраҡ** | хуже |

&emsp;

**Примеры:**
*   **Был машина осһоҙораҡ.** — Эта машина дешевле.
*   **Был компьютер ҡыйбатыраҡ.** — Этот компьютер дороже.
*   **Бөгөн кисәгә ҡарағанда йылыраҡ.** — Сегодня теплее, чем вчера.
