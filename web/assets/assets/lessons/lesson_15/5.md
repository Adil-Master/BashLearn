# 🍽️ Еда и Вкус

## Глаголы "есть" и "пить"

*   **Аша** — ешь, кушай
*   **Эс** — пей

**Примеры:**
*   **Ит ашай.** — Ест мясо.
*   **Икмәк ашай.** — Ест хлеб.
*   **Май ашамай.** — Не ест масло.
*   **Һыу эсә.** — Пьёт воду.
*   **Һөт эсмәй.** — Не пьёт молоко.
*   **Кофе эсә.** — Пьёт кофе.
*   **Какао эсмәй.** — Не пьёт какао.

## Приготовление еды

*   **Аш** — суп
*   **Аш бешереү** — варить суп
*   **Бутка** — каша
*   **Бутка бешереү** — варить кашу
*   **Салат** — салат
*   **Салат эшләү** — делать салат
*   **Һурпа** — бульон
*   **Һурпа ҡойоу** — залить бульоном

**Примеры:**
*   **Мин аш бешерәм.** — Я варю суп.
*   **Һин аш бешерәһең.** — Ты варишь суп.
*   **Ул аш бешерә.** — Он варит суп.
*   **Булат бутка ашай.** — Булат ест кашу.
*   **Атай аш ашай.** — Папа ест суп.
*   **Ләйсән салат ашай.** — Ляйсан ест салат.

## Вкус

*   **Аштарығыҙ тәмле булһын!** — Приятного аппетита! (букв. "Пусть ваша еда будет вкусной!")

| Башкирский | Русский |
|------------|---------|
| **Тәмле** | Вкусный |
| **Тәмһеҙ** | Невкусный |
| **Тоҙло** | Солёный |
| **Тоҙһоҙ** | Несолёный |
| **Әсе** | Горький, кислый |
| **Сөсө** | Пресный |
| **Татлы** | Сладкий |
