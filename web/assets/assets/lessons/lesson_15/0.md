# 🏪 В магазине

## Вопрос "Магазинға барҙыңмы?"

Чтобы спросить **ходил ли** человек в магазин, используйте прошедшее время глагола:

*   **Азат, һин магазинға барҙыңмы?** — Азат, ты ходил в магазин?
*   **Азат, һин баҙарға барҙыңмы?** — Азат, ты ходил на рынок?

&emsp;

## Виды магазинов

| Башкирский | Русский |
|------------|---------|
| **Магазин** | Магазин |
| **Баҙар** | Рынок |
| **Киоск** | Киоск |
| **Компьютерҙар магазины** | Магазин компьютеров |
| **Үҙәк баҙар** | Центральный рынок |

&emsp;

**Примеры:**
*   **Был магазинда нимә бар?** — Что есть в этом магазине?
*   **Был магазинда кофе бармы?** — В этом магазине есть кофе?
*   **Был ниндәй магазин?** — Какой это магазин?
*   **Был компьютерҙар магазинымы?** — Это магазин компьютеров?

**Диалог:**
*   **— Был «Матрица» магазинмы?** — Это магазин «Матрица»?
*   **— Эйе.** — Да.
*   **— Был «Техно» магазинмы?** — Это магазин «Техно»?
*   **— Юҡ.** — Нет.
*   **— «Техно» магазинында нимә бар?** — Что есть в магазине «Техно»?
*   **— Телевизор бар.** — Есть телевизор.
*   **— «Самрау» магазинында компьютер бармы?** — В магазине «Самрау» есть компьютер?
*   **— Юҡ.** — Нет.
