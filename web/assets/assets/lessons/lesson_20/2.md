# 🚀 Начало действия

## Конструкция "... башлау"

Для выражения **начала действия** используется деепричастие на **-а/-й** и вспомогательный глагол **башлау** (начать).

| Деепричастие + башлау | Русский |
|-----------------------|---------|
| **йырлай башлау** | запе́ть |
| **уйнай башлау** | заигра́ть |
| **көлә башлау** | засмея́ться |
| **бейей башлау** | запляса́ть |
| **ҡысҡыра башлау** | закрича́ть |
| **өрә башлау** | зала́ять |
| **илай башлау** | запла́кать |
| **аҡһай башлау** | захрома́ть |
| **яна башлау** | загоре́ться |

&emsp;

**Примеры:**
*   **Азат шатлыҡтан йырлай башланы.** — Азат от радости запел.
*   **Шатлыҡтан илай башланы.** — От радости заплакал.
*   **Мин шатлыҡтан йырлай башланым.** — Я от радости запел.
*   **Бала илай башланы.** — Ребёнок заплакал.
*   **Эт өрә башланы.** — Собака залаяла.
*   **Усаҡта ут яна башланы.** — В очаге загорелся огонь.
*   **Мәзинә йырлай башланы.** — Мадина запела.

&emsp;

**С деепричастиями:**
*   **Диңгеҙҙе күргәс, ул йырлай башланы.** — Увидев море, он запел.
*   **Көньяҡҡа килгәс, ул йырлай башланы.** — Приехав на юг, он запел.
*   **Көнбайышта ут яна башланы.** — На западе загорелся огонь.
*   **Эт көньяҡҡа ҡарап өрә башланы.** — Собака, глядя на юг, залаяла.
