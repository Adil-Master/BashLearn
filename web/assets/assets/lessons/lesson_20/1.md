# ⏳ Деепричастие прошедшего времени

## Аффиксы -ғас/-гәс, -ҡас/-кәс

Деепричастие прошедшего времени образуется с помощью аффиксов **-ғас/-гәс**, **-ҡас/-кәс** и означает **"когда сделал"** или **"сделав"**.

| Глагол | Деепричастие | Русский |
|--------|--------------|---------|
| **ҡайт** (вернись) | **ҡайтҡас** | когда вернулся (вернувшись) |
| **кит** (уходи) | **киткәс** | когда ушёл (уйдя) |
| **әйт** (скажи) | **әйткәс** | когда сказал (сказав) |
| **яҙ** (напиши) | **яҙғас** | когда написал (написав) |
| **ярат** (люби) | **яраткас** | когда полюбил (полюбив) |
| **бел** (знай) | **белгәс** | когда узнал (узнав) |
| **йәшә** (живи) | **йәшәгәс** | когда пожил (пожив) |

&emsp;

**Примеры:**
*   **Көньяҡтан ҡайтҡас, миңә килерһеңме?** — Когда вернёшься с юга, придёшь ко мне?
*   **Көньяҡҡа килгәс, йырлай башланы.** — Когда приехал на юг, начал петь.
*   **Барғас, әйтер.** — Когда придёт, скажет.
*   **Килгәс, эшләр.** — Когда придёт, сделает.

## Деепричастие настоящего времени

Аффиксы **-ып/-еп/-п** означают действие, происходящее одновременно с другим.

| Глагол | Деепричастие | Русский |
|--------|--------------|---------|
| **кил** (приходи) | **килеп** | приходя |
| **кит** (уходи) | **китеп** | уходя |
| **йәшә** (живи) | **йәшәп** | живя |
| **бар** (иди) | **барып** | идя |
| **әйт** (говори) | **әйтеп** | говоря |
| **ин** (заходи) | **инеп** | заходя |
| **ултыр** (сиди) | **ултырып** | сидя |
| **ят** (лежи) | **ятып** | лежа |

&emsp;

**Примеры:**
*   **Азат, беҙгә инеп сыҡ.** — Азат, зайди к нам.
*   **Азамат, беҙгә килеп ҡайт.** — Азамат, зайди к нам.
*   **Ямал илап ебәрҙе.** — Ямал заплакала.
*   **Ул килеп торҙо.** — Он встал.
*   **Мин йырлап ебәрҙем.** — Я запела.
*   **Тороп тор.** — Подожди (постой).
*   **Алып бир.** — Дай (возьми и дай).
*   **Ятып тор.** — Лежи.
*   **Ашап ал.** — Покушай.
