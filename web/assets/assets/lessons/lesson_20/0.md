# 🧭 Стороны света

## Названия направлений

| Башкирский | Русский |
|------------|---------|
| **Көньяҡ** | Юг, южный |
| **Төньяҡ** | Север, северный |
| **Көнсығыш** | Восток, восточный |
| **Көнбайыш** | Запад, западный |

&emsp;

**Примеры:**
*   **Башҡортостан Көньяҡ Уралда.** — Башкортостан на Южном Урале.
*   **Екатеринбург Төньяҡ Уралда.** — Екатеринбург на Северном Урале.
*   **Көнсығыш Европа.** — Восточная Европа.
*   **Көнбайыш Европа.** — Западная Европа.

**Вопросы:**
*   **— Башҡортостан ҡайҙа?** — Где Башкортостан?
*   **— Көньяҡ Уралда.** — На Южном Урале.
*   **— Махачкала ҡайҙа?** — Где Махачкала?
*   **— Төньяҡ Кавказда.** — На Северном Кавказе.
*   **— Көньяҡ Полюста нимә бар?** — Что есть на Южном полюсе?
*   **— Пингвиндар бар.** — Есть пингвины.
