# 🕐 Который час?

## Вопрос о времени

*   **Сәғәт нисә?** — Который час?

## Ответы

| Время | Башкирский |
|-------|------------|
| 1:00 | **Бер** |
| 5:10 | **Биш сәғәт ун минут** (**Алтынсы ун минут**) |
| 9:00 | **Туғыҙ** |
| 12:00 | **Ун ике** |
| 12:05 | **Ун ике сәғәт биш минут** |
| 12:30 | **Беренсе ярты** |

&emsp;

## Порядковые числительные

| Количественное | Порядковое (который по счету) |
|----------------|-------------------------------|
| бер (1) | **беренсе** (первый) |
| ике (2) | **икенсе** (второй) |
| өс (3) | **өсөнсө** (третий) |
| дүрт (4) | **дүртенсе** (четвертый) |
| биш (5) | **бишенсе** (пятый) |
| ун (10) | **унынсы** (десятый) |

&emsp;

**Примеры с порядковыми:**
*   **Икенсе биш минут** — Пять минут второго
*   **Бишенсе ярты** — Половина пятого
*   **Ун икенсе ун минут** — Десять минут двенадцатого
