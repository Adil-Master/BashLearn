# 🕐 Половина и Дополнительные Фразы

## Половина

*   **Ярты** — половина

**Примеры:**
*   **Бишенсе ярты** — Половина пятого (4:30)
*   **Унынсы ярты** — Половина десятого (9:30)
*   **Дүртенсе ярты** — Половина четвертого (3:30)

&emsp;

## Полезные фразы

*   **Белмәйем.** — Не знаю.
*   **Бер ни түгел.** — Не за что.
*   **Шулаймы?** — Разве? / Так? (удивление)
*   **Шулаймы ни?** — Вот как! / Разве так?
*   **Шулай** — Да, точно так.

&emsp;

**Примеры:**
*   **— Сәғәт нисә?** — Который час?
*   **— Белмәйем.** — Не знаю.
*   **— Рәхмәт.** — Спасибо.
*   **— Бер ни түгел.** — Не за что.
*   **— Сәғәт ун ике.** — Двенадцать.
*   **— Шулаймы?** — Разве?
*   **— Эйе, шулай шул.** — Да, точно так.
