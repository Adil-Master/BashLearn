# 💬 Как дела?

## Вопросы о состоянии

*   **Хәлдәр нисек?** — Как дела? (букв. "Как состояния?")
*   **Нихәл?** — Как дела? (краткая форма)

## Ответы

| Башкирский | Русский |
|------------|---------|
| **Яҡшы** | Хорошо |
| **Бик яҡшы** | Очень хорошо |
| **Һәйбәт** | Хорошо |
| **Шәп** | Очень хорошо |
| **Уртаса** | Средне |
| **Насар түгел** | Неплохо |
| **Насар** | Плохо |
| **Бик насар** | Очень плохо |
| **Хөрт** | Очень плохо |
| **Аллаға шөкөр** | Слава богу |

&emsp;

**Пример:**
*   **— Азат, хәлдәр нисек?** — Азат, как дела?
*   **— Рәхмәт, бик яҡшы.** — Спасибо, очень хорошо.
*   **— Нихәл, Нил?** — Как дела, Нил?
*   **— Шәп, Гүзәл.** — Отлично, Гузель.
