# 📍 Предлоги места

## Слова для обозначения места

| Башкирский | Русский |
|------------|---------|
| **ал** | Передняя часть |
| **арт** | Задняя часть |
| **өҫ** | Верх |
| **аҫ** | Низ |
| **урта** | Середина |
| **ҡаршы** | Напротив |
| **уң** | Правый |
| **һул** | Левый |

## С предлогами

| Башкирский | Русский |
|------------|---------|
| **Алда** | Впереди |
| **Артта** | Позади |
| **Өҫтә** | Наверху |
| **Аҫта** | Внизу |
| **Уртала** | В середине |
| **Ҡаршыла** | Напротив |
| **Уңда** | Направо / справа |
| **Һулда** | Налево / слева |

&emsp;

**Примеры:**
*   **— Почта ҡайҙа?** — Почта где?
*   **— Алда.** — Впереди.
*   **— Банк ҡайҙа?** — Банк где?
*   **— Ҡаршыла.** — Напротив.
*   **— Техникум ҡайҙа?** — Техникум где?
*   **— Уңда.** — Справа.
*   **— Машина аҫтамы?** — Машина внизу?
*   **— Эйе, аҫта.** — Да, внизу.

## Указательные слова

*   **Бында** — здесь, вот здесь
*   **Унда** — там, туда
*   **Тегендә** — вон там, в том месте
*   **Ана** — вон, вон там
*   **Бына** — вот

&emsp;

**Примеры:**
*   **— Миша ҡайҙа?** — Миша где?
*   **— Ана.** — Вон там.
*   **— Касса бындамы?** — Касса здесь?
*   **— Эйе, бында.** — Да, здесь.
*   **— Велосипед тегендә.** — Велосипед вон там.
