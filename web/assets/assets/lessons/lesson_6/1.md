# 🌏 Национальности и Страны

## Кто где живет?

| Национальность | Страна |
|----------------|--------|
| **башҡорт** | **Башҡортостан** — Башкортостан |
| **немец** | **Германия** — Германия |
| **француз** | **Франция** — Франция |
| **урыҫ** | **Рәсәй** — Россия |
| **йәһүд** | **Израиль** — Израиль |
| **үзбәк** | **Үзбәкстан** — Узбекистан |
| **ғәрәп** | **Мысыр** — Египет |
| **чех** | **Чехия** — Чехия |
| **мадьяр** | **Венгрия** — Венгрия |
| **поляк** | **Польша** — Польша |
| **ҡытай** | **Ҡытай** — Китай |
| **татар** | **Татарстан** — Татарстан |

&emsp;

**Примеры:**
*   **— Венгрияла кем?** — В Венгрии кто?
*   **— Венгр (мадьяр).** — Венгр.
*   **— Рәсәйҙә ғәрәп бармы?** — В России есть арабы?
*   **— Бар.** — Есть.
*   **— Башҡортостанда кем бар?** — В Башкортостане кто есть?
*   **— Башҡорт, урыҫ, татар, сыуаш...** — Башкиры, русские, татары, чуваши...
