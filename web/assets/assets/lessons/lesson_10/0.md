# 📮 Какой у вас адрес?

## Вопрос "Адресығыҙ нисек?"

Чтобы спросить **какой адрес**, используйте вопросительную конструкцию:

*   **Азат, адресығыҙ нисек?** — Азат, какой у вас адрес?
*   **Адресың нисек?** — Какой у тебя адрес?

&emsp;

## Притяжательные формы слова "адрес"

| Башкирский | Русский |
|------------|---------|
| **адресым** | мой адрес |
| **адресың (һинең адресың)** | твой адрес |
| **адресы (уның адресы)** | его/её адрес |
| **адресыбыҙ (беҙҙең адресыбыҙ)** | наш адрес |
| **адресығыҙ (һеҙҙең адресығыҙ)** | ваш адрес |
| **адресы (уларҙың адресы)** | их адрес |

&emsp;

**Пример:**
*   **Адресыбыҙ:** — Наш адрес:
*   **Башҡортостан Республикаһы, 450001, Өфө, Салауат Юлаев урамы, 10**
*   **Телефон: 50-25-37**
*   **Факс: 50-25-77**

## Пример диалога

*   **— Азат, адресың нисек?** — Азат, какой у тебя адрес?
*   **— Адресым: Ҡырҡ биш, өс нуль, ике, Өфө, Тукай урамы, 7-се һанлы йорт, 10-сы фатир.** — Мой адрес: 450002, Уфа, улица Тукай, дом 7, квартира 10.
