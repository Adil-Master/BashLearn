# 📞 Телефон и Номер

## Вопросы о телефоне

*   **Телефонығыҙ бармы?** — У вас есть телефон?
*   **Телефоның бармы?** — У тебя есть телефон?

## Притяжательные формы слова "телефон"

| Башкирский | Русский |
|------------|---------|
| **телефоным** | мой телефон |
| **телефоның** | твой телефон |
| **телефоны** | его/её телефон |
| **телефоныбыҙ** | наш телефон |
| **телефонығыҙ** | ваш телефон |
| **телефоны** | их телефон |

&emsp;

**Примеры:**
*   **— Һинең телефоның бармы?** — У тебя есть телефон?
*   **— Бар.** — Есть.
*   **— Уларҙың телефоны бармы?** — У них есть телефон?
*   **— Юҡ.** — Нет.
*   **— Был һинең телефонымы?** — Это твой телефон?
*   **— Түгел.** — Нет.

## Вопросы о номере

*   **Номеры нисек?** — Какой номер?
*   **Өйҙөң номеры.** — Номер дома.
*   **Телефон номеры.** — Номер телефона.
*   **Машина номеры.** — Номер машины.

**Примеры:**
*   **— Телефонығыҙҙың номеры нисек?** — Какой у вас номер телефона?
*   **— Телефоныбыҙҙың номеры: 37-19-12.** — Наш номер телефона: 37-19-12.
*   **— Телефоның бармы?** — У тебя есть телефон?
*   **— Бар.** — Есть.
*   **— Номеры нисек?** — Какой номер?
*   **— Бына визиткам.** — Вот моя визитка.
*   **— Рәхмәт. Бына минең визиткам.** — Спасибо. Вот моя визитка.
