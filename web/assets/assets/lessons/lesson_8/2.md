# 🚀 Глаголы движения с направлениями

## Полная таблица глаголов движения

| Глагол | Значение | Пример |
|--------|----------|--------|
| **барыу** | идти, ехать (туда) | **Мин ҡалаға барам.** — Я еду в город. |
| **килеү** | идти, ехать (сюда) | **Мин ҡаланан киләм.** — Я еду из города. |
| **китеү** | уходить, уезжать (отсюда) | **Мин ҡаланан китәм.** — Я уезжаю из города. |
| **ҡайтыу** | возвращаться | **Мин ҡалаға ҡайтам.** — Я возвращаюсь в город. |

&emsp;

**Примеры с разными направлениями:**
*   **Кәрим килә.** — Карим приходит.
*   **Алмаз ҡайта.** — Алмаз возвращается.
*   **Кәримә китә.** — Карима уходит.
*   **Ғәли бара.** — Гали идёт.

*   **Мәскәүҙән килә.** — Приезжает из Москвы.
*   **Пекиндан ҡайта.** — Возвращается из Пекина.
*   **Парижға китә.** — Уезжает в Париж.
*   **Делигә бара.** — Едет в Дели.

**Вопросы:**
*   **Кем Мәскәүгә китә?** — Кто уезжает в Москву?
*   **Кем Төркиәнән килә?** — Кто приезжает из Турции?
*   **Кем Баймаҡҡа ҡайта?** — Кто возвращается в Баймак?
*   **Әмир киләме?** — Амир приходит?
*   **Вил ҡайтамы?** — Вил возвращается?
