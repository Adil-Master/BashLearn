# 📝 Практика: Вопросы и Ответы

## Закрепление материала

Теперь вы умеете:
1. Спрашивать **откуда** человек (*Кайҙан?*)
2. Спрашивать **кто** человек (*Кем?*)
3. Представлять людей (*Таныш бул!*)
4. Использовать вежливые фразы

&emsp;

## Примеры вопросов для практики

*   **Һин ҡайҙан?** — Ты откуда?
*   **Ул студентмы?** — Он студент?
*   **Был кем?** — Кто это?
*   **Һеҙ инженермы?** — Вы инженер?
*   **Мөмкинме?** — Можно?
