# 🔍 Чей это?

## Вопрос "Кемдеке?"

Чтобы спросить **чей** предмет, используйте вопросительное слово **Кемдеке?**

*   **Компьютер кемдеке?** — Компьютер чей?
*   **Азаттыҡы.** — Азата.
*   **Журнал атайҙыҡы.** — Журнал отца.

&emsp;

## Притяжательные местоимения

| Башкирский | Русский |
|------------|---------|
| **Минеке** | Мой, моя, моё, мои |
| **Һинеке** | Твой, твоя, твоё, твои |
| **Уныҡы** | Его, её |
| **Беҙҙеке** | Наш, наша, наше, наши |
| **Һеҙҙеке** | Ваш, ваша, ваше, ваши |
| **Уларҙыҡы** | Их |

&emsp;

**Примеры:**
*   **— Журнал кемдеке?** — Журнал чей?
*   **— Минеке.** — Мой.
*   **— Машина һинекеме?** — Машина твоя?
*   **— Эйе, минеке.** — Да, моя.
*   **— Был гитара һеҙҙекеме?** — Эта гитара ваша?
*   **— Юк, беҙҙеке түгел.** — Нет, не наша.
*   **— Компьютер уныҡымы?** — Компьютер его?
*   **— Юк, уныҡы түгел, минеке.** — Нет, не его, а мой.

> 📝 Внимание: аффикс -кы/-ке/-ҡы добавляется к существительным для образования значения принадлежности!
