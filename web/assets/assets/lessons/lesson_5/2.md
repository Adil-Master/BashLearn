# 👕 Одежда

## Названия одежды

| Башкирский | Русский |
|------------|---------|
| **бүрек** | Шапка |
| **тун** | Шуба |
| **итек** | Сапоги |
| **эшләпә** | Шляпа |
| **пальто** | Пальто |
| **быйма** | Валенки |
| **шәл** | Шаль |
| **күлдәк** | Платье (рубашка) |
| **кроссовка** | Кроссовки |
| **яулыҡ** | Платок |
| **салбар** | Брюки |
| **туфли** | Туфли |
| **түбәтәй** | Тюбетейка |
| **свитер** | Свитер |
| **калуш** | Галоши |

&emsp;

**Примеры:**
*   **— Азат, был нимә?** — Азат, что это?
*   **— Түбәтәй.** — Тюбетейка.
*   **— Оля, был свитермы?** — Оля, это свитер?
*   **— Эйе, свитер.** — Да, свитер.
*   **— Быйма һинекеме?** — Валенки твои?
*   **— Юк, олатайҙыҡы.** — Нет, дедушки.
*   **— Кейем уларҙыҡымы?** — Их одежда?
*   **— Эйе, уларҙыҡы.** — Да, их.

> 🎯 Запомните названия одежды — они часто встречаются в повседневной жизни!
