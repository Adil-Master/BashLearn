# 🎮 Практика: Вопросы и Ответы

## Закрепление материала

Теперь вы умеете:
1. Спрашивать **что** это (*Нимә?*)
2. Спрашивать **чей** предмет (*Кемдеке?*)
3. Использовать притяжательные местоимения (*Минеке, Һинеке, Уныҡы*)
4. Называть предметы и одежду

&emsp;

## Примеры вопросов для практики

*   **Был нимә?** — Что это?
*   **Машина кемдеке?** — Машина чья?
*   **Быйма һинекеме?** — Валенки твои?
*   **Скейт олатайҙыҡымы?** — Скейт дедушкин?
*   **Мотоцикл һеҙҙекеме?** — Мотоцикл ваш?
