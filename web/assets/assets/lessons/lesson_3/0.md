# 🌍 Откуда ты?

## Вопрос "Ҡайҙан?"

Чтобы спросить **откуда** человек, используйте вопросительное слово **Ҡайҙан?**

*   **Азат, һин ҡайҙан?** — Азат, ты откуда?
*   **Сибайҙан.** — Из Сибая.

&emsp;

## Аффиксы исходного падежа

Для ответа на вопрос "откуда?" используются окончания:

*   **-дан/-дән** — после звонких согласных: *л, м, н, ң, з, ж*
    *   **Башҡортостандан** — из Башкортостана
*   **-тан/-тән** — после глухих согласных
    *   **Баймаҡтан** — из Баймака
*   **-ҙан/-ҙән** — после *й, р, и, у, ү, ҙ*
    *   **Мәскәүҙән** — из Москвы
    *   **Сибайҙан** — из Сибая
*   **-нан/-нән** — после гласных
    *   **Өфөнән** — из Уфы
    *   **Канаданан** — из Канады

> 📝 Запомните: выбор аффикса зависит от последней буквы слова!
