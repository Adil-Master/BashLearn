# 💭 Выражение желания

## Конструкция "...ғы килә"

В башкирском языке желание передается с помощью аффиксов **-ғы/-ге, -ҡы/-ке** и вспомогательного глагола **килә**.

## Образец: глагол барыу (идти)

| Лицо | Башкирский | Русский |
|------|------------|---------|
| Мин | **Минең барғым килә** | Мне хочется идти |
| Һин | **Һинең барғың килә** | Тебе хочется идти |
| Ул | **Уның барғыһы килә** | Ему хочется идти |
| Беҙ | **Беҙҙең барғыбыҙ килә** | Нам хочется идти |
| Һеҙ | **Һеҙҙең барғығыҙ килә** | Вам хочется идти |
| Улар | **Уларҙың барғыһы килә** | Им хочется идти |

&emsp;

**Примеры с разными глаголами:**
*   **Минең ҡарағым килә.** — Мне хочется посмотреть.
*   **Һинең күргең килә.** — Тебе хочется увидеть.
*   **Уның белеге килә.** — Ему хочется знать.
*   **Беҙҙең яҙғыбыҙ килә.** — Нам хочется написать.
*   **Һеҙҙең киткегеҙ килә.** — Вам хочется уйти.
*   **Уларҙың уҡығыһы килә.** — Им хочется читать.
*   **Минең йөҙгөм килә.** — Мне хочется плавать.

&emsp;

**Примеры с транспортом:**
*   **Мин поезд менән йөрөгөм килә.** — Мне хочется ездить на поезде.
*   **Мин самолет менән осҡом килә.** — Мне хочется лететь на самолёте.
*   **Уның автобус менән киткеһе килә.** — Ему хочется уехать на автобусе.
