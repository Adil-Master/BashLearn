# Что такое BashLearn?
### BashLearn помогает познакомиться с башкирским языком с нуля — от первых слов и звуков до простых предложений.

- **Бесплатно.** Весь курс доступен без подписки и регистрации.
- **Кроссплатформенно.** Работает на телефоне, планшете и компьютере.
- **Интерактивно.** Не просто читать — сразу применять знания на практике.
