# 🏆 Соревнования

## Ключевые слова

| Башкирский | Русский |
|------------|---------|
| **Ярыш** | Соревнование |
| **Ярыш асыу** | Открытие соревнования |
| **Ярыш ябыу** | Закрытие соревнования |
| **Ярыш башлау** | Начинать соревнование |
| **Ярышта ҡатнашыу** | Участвовать в соревновании |
| **Ярышта еңеү** | Победить в соревновании |
| **Ярышта еңелеү** | Проиграть в соревновании |
| **Ярышка барыу** | Идти на соревнование |
| **Ярышта булыу** | Быть на соревновании |

&emsp;

## Виды соревнований

| Башкирский | Русский |
|------------|---------|
| **Саңғы ярышы** | Соревнования по лыжам |
| **Сана ярышы** | Соревнования на санках |
| **Теннис ярышы** | Соревнования по теннису |

&emsp;

**Примеры:**
*   **— Бөгөн саңғы ярышы буламы?** — Сегодня будут соревнования по лыжам?
*   **— Эйе.** — Да.
*   **— Иртәгә теннис ярышы буламы?** — Завтра будут соревнования по теннису?
*   **— Юҡ.** — Нет.
*   **— Ҡасан саңғы ярышы була?** — Когда будут соревнования по лыжам?
*   **— Сәғәт 10:00.** — В 10:00.
*   **— Ҡасан саңғы ярышы башлана?** — Когда начинаются соревнования по лыжам?
*   **— Сәғәт 11:00.** — В 11:00.
*   **— Ҡасан саңғы ярышы ябыла?** — Когда закрываются соревнования по лыжам?
*   **— Сәғәт киске алтыла.** — В 18:00.
*   **— Айһылыу, ярышка бараһыңмы?** — Айсылу, ты идёшь на соревнования?
*   **— Барам.** — Иду.
*   **— Айҙар, саңғы ярышында кем еңде?** — Айдар, кто победил в соревнованиях по лыжам?
*   **— Мин.** — Я.
