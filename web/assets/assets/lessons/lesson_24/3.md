# 🏀 Игры с мячом

## Ключевые слова

| Башкирский | Русский |
|------------|---------|
| **Туп** | Мяч |
| **Туп уйнау** | Играть в мяч |
| **Туп һуғыу** | Ударять по мячу |
| **Туп тибеү** | Бить (ногой) по мячу |
| **Туп ташлау** | Бросить мяч |
| **Туп ырғытыу** | Кидать мяч |

&emsp;

## Спортсмены по видам игр

| Башкирский | Русский |
|------------|---------|
| **Футболсы** | Футболист |
| **Волейболсы** | Волейболист |
| **Баскетболсы** | Баскетболист |
| **Тенниссы** | Теннисист |
| **Хоккейсы** | Хоккеист |

&emsp;

**Примеры:**
*   **— Кем туп менән уйнай?** — Кто играет с мячом?
*   **— Волейболсы, футболсы, баскетболсы.** — Волейболист, футболист, баскетболист.
*   **— Кем тупты тибеп уйнай?** — Кто играет, ударяя по мячу ногой?
*   **— Футболсы.** — Футболист.
*   **— Кем тупты һуғып уйнай?** — Кто играет, ударяя по мячу рукой?
*   **— Волейболсы.** — Волейболист.
*   **— Кем тупты кәрзингә ташлай?** — Кто бросает мяч в корзину?
*   **— Баскетболсы.** — Баскетболист.
*   **— Кем йөн туп менән уйнай?** — Кто играет мячом с ворсом?
*   **— Тенниссы.** — Теннисист.

## Вопросы о спорте

*   **— Һин туп уйындарын яратаһыңмы?** — Ты любишь игры с мячом?
*   **— Эйе.** — Да.
*   **— Һин ниндәй туп уйынын яратаһың?** — Какую игру с мячом ты любишь?
*   **— Футбол.** — Футбол.
