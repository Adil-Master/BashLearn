# 🥇 Олимпийские игры

## Ключевые слова

| Башкирский | Русский |
|------------|---------|
| **Олимпия уйындары** | Олимпийские игры |
| **Олимпия ярыштары** | Олимпийские соревнования |
| **Олимпия чемпионы** | Олимпийский чемпион |
| **Донъя чемпионы** | Чемпион мира |

&emsp;

**Примеры:**
*   **— Олимпия уйындары ҡасан була?** — Когда бывают Олимпийские игры?
*   **— Белмәйем.** — Не знаю.
*   **— Олимпия уйындары ҡайҙа була?** — Где бывают Олимпийские игры?
*   **— Мәскәүҙә.** — В Москве.
*   **— Олимпия ярыштарына барабыҙмы?** — Мы пойдём на Олимпийские соревнования?
*   **— Эйе.** — Да.
*   **— Һин Олимпия уйындарына бараһыңмы?** — Ты идёшь на Олимпийские игры?
*   **— Барам.** — Иду.

## Чемпионы

*   **— Һин республиканың Олимпия чемпиондарын беләһеңме?** — Ты знаешь олимпийских чемпионов республики?
*   **— Белмәйем.** — Не знаю.
*   **— Республикала Олимпия чемпиондары бармы?** — В республике есть олимпийские чемпионы?
*   **— Бар.** — Есть.
*   **— Һин Олимпия чемпионы булырға теләйһеңме?** — Ты хочешь стать олимпийским чемпионом?
*   **— Юҡ.** — Нет.
*   **— Азат донъя чемпионы булырға теләйме?** — Азат хочет стать чемпионом мира?
*   **— Эйе.** — Да.
