# ⚽ Виды спорта

## Вопрос "Һин спорт яратаһыңмы?"

*   **Азат, һин спорт яратаһыңмы?** — Азат, ты любишь спорт?

## Основные виды спорта

| Башкирский | Русский |
|------------|---------|
| **Футбол** | Футбол |
| **Волейбол** | Волейбол |
| **Баскетбол** | Баскетбол |
| **Теннис** | Теннис |
| **Хоккей** | Хоккей |
| **Көрәш** | Борьба |
| **Милли көрәш** | Национальная борьба |
| **Йөҙөү** | Плавание |
| **Бокс** | Бокс |
| **Гимнастика** | Гимнастика |

&emsp;

**Примеры:**
*   **— Һин спорт яратаһыңмы?** — Ты любишь спорт?
*   **— Эйе.** — Да.
*   **— Һин футбол яратаһыңмы?** — Ты любишь футбол?
*   **— Юҡ.** — Нет.
*   **— Ул хоккей яратамы?** — Он любит хоккей?
*   **— Эйе, ярата.** — Да, любит.
*   **— Һин спорт төрҙәрен беләһеңме?** — Ты знаешь виды спорта?
*   **— Беләм.** — Знаю.
*   **— Һин көрәш төрҙәрен беләһеңме?** — Ты знаешь виды борьбы?
*   **— Юҡ.** — Нет.
