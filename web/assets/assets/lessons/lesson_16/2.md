# 🎨 Цвета

## Названия цветов

| Башкирский | Русский |
|------------|---------|
| **Ҡыҙыл** | Красный |
| **Йәшел** | Зелёный |
| **Аҡ** | Белый |
| **Ҡара** | Чёрный |
| **Күк** | Синий |
| **Һары** | Жёлтый |
| **Көрән** | Коричневый |
| **Һоро** | Серый |

&emsp;

**Примеры:**
*   **Ҡыҙыл алма.** — Красное яблоко.
*   **Йәшел ҡыяр.** — Зелёный огурец.
*   **Аҡ ҡарағат.** — Белая смородина.
*   **Ҡара ҡарағат.** — Чёрная смородина.
*   **Күк сәскә.** — Синий цветок.
*   **Һары ҡауын.** — Жёлтая дыня.
*   **Көрән сейә.** — Коричневая вишня.
*   **Һоро бесәй.** — Серый кот.

**Вопросы:**
*   **— Алма ниндәй?** — Какое яблоко?
*   **— Ҡыҙыл.** — Красное.
*   **— Һарымһаҡ ниндәй?** — Какой чеснок?
*   **— Аҡ.** — Белый.
*   **— Һуған ниндәй?** — Какой лук?
*   **— Әсе.** — Горький.
*   **— Ҡауын һарымы?** — Дыня жёлтая?
*   **— Эйе.** — Да.
*   **— Ҡарбуз һарымы?** — Арбуз жёлтый?
*   **— Юҡ, ҡыҙыл.** — Нет, красный.
