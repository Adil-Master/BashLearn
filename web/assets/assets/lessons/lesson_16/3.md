# 📏 Размер и Свойства

## Размер

| Башкирский | Русский |
|------------|---------|
| **Эре** | Крупный |
| **Ваҡ** | Мелкий |

**Примеры:**
*   **— Ҡарбуз үҫәме?** — Арбуз растёт?
*   **— Эйе.** — Да.
*   **— Ҡарбуз эреме?** — Арбуз крупный?
*   **— Юҡ.** — Нет.
*   **— Азат, эре һуған ал.** — Азат, возьми крупный лук.
*   **— Азат, ҡарбуз алдыңмы?** — Азат, ты взял арбуз?
*   **— Эйе.** — Да.

## Свойства поверхности

| Башкирский | Русский |
|------------|---------|
| **Ҡаты** | Твёрдый, жёсткий |
| **Йомшаҡ** | Мягкий, рыхлый |

**Примеры:**
*   **Ер ҡаты.** — Земля твёрдая.
*   **Ҡаты ер.** — Твёрдая земля.
*   **Йомшаҡ ер.** — Мягкая земля.
*   **Ер йомшаҡ.** — Земля мягкая.
*   **— Алма ҡатымы?** — Яблоко твёрдое?
*   **— Эйе.** — Да.
*   **— Ҡар йомшаҡмы?** — Снег мягкий?
*   **— Эйе, йомшаҡ.** — Да, мягкий.
*   **— Икмәк йомшаҡмы?** — Хлеб мягкий?
*   **— Юҡ, ҡаты.** — Нет, твёрдый.
