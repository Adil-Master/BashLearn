# 🌳 Есть ли у вас сад?

## Вопрос "Баҡсағыҙ бармы?"

Чтобы спросить **есть ли сад**, используйте конструкцию с **бар**:

*   **Баҡсағыҙ бармы?** — Есть ли у вас сад?
*   **Уларҙың баҡсаһы ҡайҙа?** — Где их сад?
*   **Баҡсала нимә бар?** — Что есть в саду?

&emsp;

**Примеры:**
*   **— Баҡсағыҙ бармы?** — Есть ли у вас сад?
*   **— Бар.** — Есть.
*   **— Уларҙың баҡсаһы ҡайҙа?** — Где их сад?
*   **— Шишмәлә.** — В Шишме.
*   **— Баҡсала нимә бар?** — Что есть в саду?
*   **— Еләк, йәшелсә, емеш бар.** — Есть ягоды, овощи, фрукты.
*   **— Һин баҡса яратаһыңмы?** — Ты любишь сад?
*   **— Яратмайым.** — Не люблю.
*   **— Кем баҡса ярата?** — Кто любит сад?
*   **— Олатай.** — Дедушка.

## Размер сада

| Башкирский | Русский |
|------------|---------|
| **Ҙур** | Большой |
| **Бәләкәй** | Маленький |

**Примеры:**
*   **— Баҡсағыҙ ҙурмы?** — Ваш сад большой?
*   **— Эйе.** — Да.
*   **— Уларҙың баҡсаһы ҙурмы?** — Их сад большой?
*   **— Юҡ, бәләкәй.** — Нет, маленький.
