# 🌸 Цветы и Инфинитив

## Цветы

| Башкирский | Русский |
|------------|---------|
| **Сәскә** | Цветок |
| **Аҡсәскә** | Ромашка |
| **Күксәскә** | Василёк |
| **Миләүшә** | Фиалка |
| **Роза сәскәһе** | Роза |
| **Сирень сәскәһе** | Сирень |

**Примеры:**
*   **Сәскәләр бар.** — Есть цветы.
*   **Роза үҫә.** — Роза растёт.
*   **Сирень бар.** — Есть сирень.
*   **— Һин сәскә яратаһыңмы?** — Ты любишь цветы?
*   **— Эйе.** — Да.
*   **— Атайың сәскә яратамы?** — Твой папа любит цветы?
*   **— Юҡ.** — Нет.

## Инфинитив глаголов

Инфинитив (начальная форма глагола) образуется с помощью аффиксов **-рға/-ргә**, **-ырға/-ергә**, **-арға/-әргә**:

| Глагол | Инфинитив | Русский |
|--------|-----------|---------|
| **Бар** | **Барырға** | Идти, ехать |
| **Кит** | **Китергә** | Уходить |
| **Кил** | **Килергә** | Приходить |
| **Ал** | **Алырға** | Брать |
| **Бир** | **Бирергә** | Давать |
| **Йәшә** | **Йәшәргә** | Жить |
| **Тор** | **Торорға** | Стоять, проживать |
| **Ултыр** | **Ултырырға** | Сидеть |
| **Аша** | **Ашарға** | Есть |
| **Эс** | **Эсергә** | Пить |
| **Һөйлә** | **Һөйләргә** | Говорить |
| **Уҡы** | **Уҡырға** | Читать |
| **Өйрән** | **Өйрәнергә** | Изучать |

&emsp;

**Примеры:**
*   **— Һин эшләргә яратаһыңмы?** — Ты любишь работать?
*   **— Эйе.** — Да.
*   **— Баҡсала эшләргә яратаһыңмы?** — Ты любишь работать в саду?
*   **— Юҡ.** — Нет.
*   **— Кем баҡсала эшләргә ярата?** — Кто любит работать в саду?
*   **— Әсәй.** — Мама.
*   **— Кем баҡсала эшләргә яратмай?** — Кто не любит работать в саду?
*   **— Азат.** — Азат.
