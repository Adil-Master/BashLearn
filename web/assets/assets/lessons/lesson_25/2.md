# 🎬 Фильмы и Сериалы

## Жанры фильмов

| Башкирский | Русский |
|------------|---------|
| **Нәфис фильм** | Художественный фильм |
| **Мультфильм** | Мультфильм |
| **Йәнһүрәт** | Мультфильм (анимация) |
| **Сериал** | Сериал |
| **Детектив** | Детектив |

&emsp;

**Примеры:**
*   **— Һин телефильм ҡарайһыңмы?** — Ты смотришь телефильмы?
*   **— Эйе.** — Да.
*   **— Азат нәфис фильм ҡараймы?** — Азат смотрит художественные фильмы?
*   **— Юҡ.** — Нет.
*   **— Азат, кем сериал ҡарай?** — Азат, кто смотрит сериалы?
*   **— Әсәй.** — Мама.
*   **— Азат, әсәйең ниндәй сериал ҡарай?** — Азат, какой сериал смотрит твоя мама?
*   **— «Леди Бомж».** — «Леди Бомж».
*   **— «Каменская» сериалын һин ҡарайһыңмы?** — Ты смотришь сериал «Каменская»?
*   **— Юҡ.** — Нет.
*   **— Азат, һин йәнһүрәт яратаһыңмы?** — Азат, ты любишь мультфильмы?
*   **— Эйе.** — Да.
