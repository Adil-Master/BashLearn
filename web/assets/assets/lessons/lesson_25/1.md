# 📺 Программы на БСТ

## Программы башкирского телевидения

| Башкирский | Русский |
|------------|---------|
| **Сәләм** | Привет |
| **Яңылыҡ** | Новость |
| **Сәңгелдәк** | Колыбель |
| **Хазина** | Сокровище |
| **Хәбәрҙәр** | Новости |
| **Сулпы** | Накосник |
| **Аҡ тирәк, күк тирәк** | Название игры |
| **Тай-тулак** | Конский молодняк |
| **Гөлсәр һандуғас** | Хрустальный соловей |
| **Артылыш** | Перевал |

&emsp;

**Примеры:**
*   **— Һин БСТ каналында нимә ҡарайһың?** — Что ты смотришь на канале БСТ?
*   **— «Сәләм», «Яңылыҡтар», «Сәңгелдәк», «Хазина».**
*   **— РТР каналында нимәләр ҡарайһың?** — Что ты смотришь на канале РТР?
*   **— «Хәбәрҙәр», «Сулпылар», «Телекомпас».**
*   **— НТВ каналында нимәләр ҡарарға яратаһың?** — Что ты любишь смотреть на канале НТВ?
*   **— «Намедни» тапшырыуын.** — Программу «Намедни».
*   **— «Культура» каналында нимәләр ҡарарға яратаһың?** — Что ты любишь смотреть на канале «Культура»?
*   **— Тарихи кинолар.** — Исторические фильмы.

## Ток-шоу

*   **Ток-шоу** — ток-шоу
*   **— Азат, һин ток-шоу ҡарарға яратаһыңмы?** — Азат, ты любишь смотреть ток-шоу?
*   **— Юҡ.** — Нет.
*   **— Ҡыҙҙар, кем «Аҡ тирәк, күк тирәк» ток-шоу программаһын ҡарарға теләй?** — Девушки, кто хочет посмотреть ток-шоу «Аҡ тирәк, күк тирәк»?
*   **— Мин.** — Я.
*   **— «Тай-тулак» тапшырыуында кемдәр ҡатнаша?** — Кто участвует в программе «Тай-тулак»?
*   **— Йәштәр, үҫмерҙәр.** — Молодёжь, подростки.
*   **— «Гөлсәр һандуғас» тапшырыуы һиңә оҡшаймы?** — Тебе нравится программа «Гөлсәр һандуғас»?
*   **— Эйе.** — Да.
