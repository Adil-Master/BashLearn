# 🏆 Спортивные передачи

## Спорт на телевизоре

| Башкирский | Русский |
|------------|---------|
| **Спорт каналы** | Спортивный канал |
| **Спорт буйынса тапшырыу** | Передача по спорту |
| **Чемпионат күрһәтеү** | Показать чемпионат |
| **Ярыш күрһәтеү** | Показать соревнование |

&emsp;

**Примеры:**
*   **— Азат, һеҙҙә спорт каналы эшләйме?** — Азат, у вас работает спортивный канал?
*   **— Эйе, НТВ-спорт.** — Да, НТВ-спорт.
*   **— Башҡа каналдарҙа спорт тураһында тапшырыуҙар бармы?** — На других каналах есть передачи о спорте?
*   **— Бар.** — Есть.
*   **— Һин телевизорҙан автоярыш ҡарарға яратаһыңмы?** — Ты любишь смотреть по телевизору автогонки?
*   **— Эйе.** — Да.
*   **— Хоккей буйынса Рәсәй чемпионатын ҡарайһығыҙмы?** — Вы смотрите чемпионат России по хоккею?
*   **— Эйе.** — Да.
*   **— Әсәйең телевизорҙан бокс ярышын ҡараймы?** — Твоя мама смотрит по телевизору соревнования по боксу?
*   **— Юҡ.** — Нет.
*   **— Ниңә әсәйең бокс ярышын ҡарарға яратмай?** — Почему твоя мама не любит смотреть соревнования по боксу?
*   **— Ҡандан ҡурҡа.** — Боится крови.
*   **— Әсәйең телевизорҙан концерт ҡарарға яратамы?** — Твоя мама любит смотреть по телевизору концерты?
*   **— Яратмай.** — Не любит.
