# 📺 Телевидение

## Вопрос "Һин телевизор ҡарарға яратаһыңмы?"

*   **Азат, һин телевизор ҡарарға яратаһыңмы?** — Азат, ты любишь смотреть телевизор?
*   **Телевизор ҡарау** — просмотр телевизора

## Телевизионные каналы

| Башкирский | Русский |
|------------|---------|
| **ОРТ** | ОРТ (Первый канал) |
| **РТР** | РТР (Россия) |
| **НТВ** | НТВ |
| **БСТ** | БСТ (Башкирское спутниковое телевидение) |
| **Культура** | Культура |

&emsp;

**Примеры:**
*   **— Азат, һин телевизор ҡарарға яратаһыңмы?** — Азат, ты любишь смотреть телевизор?
*   **— Эйе.** — Да.
*   **— Азат, ағайың телевизор ҡараймы?** — Азат, твой брат смотрит телевизор?
*   **— Юҡ.** — Нет.
*   **— Азат, һин ниндәй канал ҡарайһың?** — Азат, какой канал ты смотришь?
*   **— ОРТ.** — ОРТ.
*   **— Азат, атайың ниндәй канал ҡарарға ярата?** — Азат, какой канал твой папа любит смотреть?
*   **— НТВ.** — НТВ.
*   **— Азат, әсәйең «Культура» каналын ҡараймы?** — Азат, твоя мама смотрит канал «Культура»?
*   **— Эйе.** — Да.
*   **— Ағайың РТР каналын ҡарамаймы?** — Твой брат не смотрит канал РТР?
*   **— Юҡ.** — Нет.
