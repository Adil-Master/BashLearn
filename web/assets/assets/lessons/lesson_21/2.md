# 👥 Народы Башкортостана

## Национальности

| Башкирский | Русский |
|------------|---------|
| **Башҡорт** | Башкир |
| **Урыҫ** | Русский |
| **Татар** | Татарин |
| **Сыуаш** | Чуваш |
| **Мари** | Мариец |
| **Удмурт** | Удмурт |
| **Мордва** | Мордвин |
| **Немец** | Немец |

| **Төп халыҡ** | Коренной народ |

&emsp;

**Вопросы и ответы:**
*   **— Башҡортостанда ниндәй халыҡтар йәшәй?** — Какие народы живут в Башкортостане?
*   **— Башҡорт, урыҫ, татар һәм башҡалар.** — Башкиры, русские, татары и другие.
*   **— Башҡортостандың төп халҡын беләһеңме?** — Знаешь коренной народ Башкортостана?
*   **— Эйе, башҡорт.** — Да, башкиры.

**Исторические справки:**
*   **— Башҡортостанға урыҫтар ҡасан килгән?** — Когда русские пришли в Башкортостан?
*   **— Ун алтынсы-егерменсе быуаттарҙа.** — В XVI-XX веках.
*   **— Башҡортостанға татарҙар ҡасан килгән?** — Когда татары пришли в Башкортостан?
*   **— Ун алтынсы-ун туғыҙынсы быуаттарҙа.** — В XVI-XIX веках.

**Языки:**
*   **— Башҡортостанда урыҫтар башҡорт телен беләме?** — Русские в Башкортостане знают башкирский язык?
*   **— Юҡ.** — Нет.
*   **— Башҡорттар урыҫ телен беләме?** — Башкиры знают русский язык?
*   **— Белә.** — Знают.
*   **— Башҡортостанда башҡорт телен өйрәнергә кәрәкме?** — Нужно ли в Башкортостане учить башкирский язык?
*   **— Кәрәк.** — Нужно.
*   **— Беҙгә ниндәй телдәр кәрәк?** — Какие языки нам нужны?
*   **— Башҡорт, урыҫ, инглиз һәм туған тел.** — Башкирский, русский, английский и родной язык.
