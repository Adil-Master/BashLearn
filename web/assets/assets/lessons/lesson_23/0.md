# 🕐 Свободное время

## Буш ваҡыт

*   **Буш ваҡыт** — свободное время

## Вопрос "Буш ваҡытыңда нимә эшләйһең?"

*   **Азат, буш ваҡытыңда нимә эшләйһең?** — Азат, что ты делаешь в свободное время?
*   **Буш ваҡытта интернетта гиҙәм.** — В свободное время путешествую по интернету.

&emsp;

## Глагол гиҙеү (путешествовать, бродить)

| Лицо | Башкирский | Русский |
|------|------------|---------|
| Мин | **гиҙәм** | Я путешествую |
| Һин | **гиҙәһең** | Ты путешествуешь |
| Ул | **гиҙә** | Он путешествует |
| Беҙ | **гиҙәбеҙ** | Мы путешествуем |
| Һеҙ | **гиҙәһегеҙ** | Вы путешествуете |
| Улар | **гиҙә (гиҙәләр)** | Они путешествуют |

&emsp;

**Примеры:**
*   **— Һин интернетта гиҙәһеңме?** — Ты путешествуешь по интернету?
*   **— Эйе.** — Да.
*   **— Улар интернетта гиҙәме?** — Они путешествуют по интернету?
*   **— Юҡ.** — Нет.
*   **— Буш ваҡытыңда Һин интернетта гиҙәһеңме?** — В свободное время ты путешествуешь по интернету?
*   **— Эйе, гиҙәм.** — Да, путешествую.
*   **— Буш ваҡытыңда Һин интернетта гиҙергә яратаһыңмы?** — Ты любишь путешествовать по интернету в свободное время?
*   **— Яратам.** — Люблю.
*   **— Һин хакер түгелме?** — Ты не хакер?
*   **— Юҡ.** — Нет.
