# 🎨 Рисование

## Выражение "любить рисовать"

*   **Буш ваҡытта мин һүрәт төшөрөргә яратам.** — В свободное время я люблю рисовать.
*   **Һүрәт төшөрөү** — рисовать, писать картину

## Инструменты для рисования

| Башкирский | Русский |
|------------|---------|
| **Ҡәләм** | Карандаш |
| **Буяу** | Краска |
| **Төҫлө ҡәләм** | Цветной карандаш |
| **Акварель буяу** | Акварельная краска |
| **Майлы буяу** | Масляная краска |

## Жанры живописи

| Башкирский | Русский |
|------------|---------|
| **Пейзаж** | Пейзаж |
| **Портрет** | Портрет |

&emsp;

**Примеры:**
*   **— Һин һүрәт төшөрәһеңме?** — Ты рисуешь?
*   **— Юҡ.** — Нет.
*   **— Һин һүрәт төшөрөргә яратаһыңмы?** — Ты любишь рисовать?
*   **— Эйе.** — Да.
*   **— Буш ваҡытыңда һүрәт төшөрәһеңме?** — Ты рисуешь в свободное время?
*   **— Эйе.** — Да.
*   **— Кем һүрәт төшөрөргә ярата?** — Кто любит рисовать?
*   **— Илгиз.** — Ильгиз.

**Диалог:**
*   **— Һин нимә менән һүрәт төшөрәһең?** — Чем ты рисуешь?
*   **— Төҫлө ҡәләм менән.** — Цветными карандашами.
*   **— Һин нимә менән һүрәт төшөрөргә яратаһың?** — Чем ты любишь рисовать?
*   **— Акварель буяу менән.** — Акварелью.
*   **— Һин һүрәтте майлы буяу менән төшөрәһеңме?** — Ты рисуешь масляными красками?
*   **— Юҡ.** — Нет.
*   **— Азат ниндәй һүрәт төшөргән?** — Какую картину нарисовал Азат?
*   **— Пейзаж.** — Пейзаж.
*   **— Һин ниндәй һүрәт төшөрҙөң?** — Какую картину ты нарисовал?
*   **— Портрет.** — Портрет.
*   **— Азат портрет төшөрөргә яратамы?** — Азат любит рисовать портреты?
*   **— Юҡ.** — Нет.
*   **— Һин пейзаж төшөрөргә яратаһыңмы?** — Ты любишь рисовать пейзажи?
*   **— Яратам.** — Люблю.
