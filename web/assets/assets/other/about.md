# О BashLearn

> ### **BashLearn** — бесплатное приложение для изучения башкирского языка, разработанное на фреймворке Flutter.

---

## 📖 Что внутри

- Интерактивные уроки с теорией и практикой
- Аудиосопровождение от носителей языка
- Тесты для закрепления материала
- Система прогресса и наград

---

## 🛠 Технологии

- Flutter / Dart
- Markdown для оформления уроков
- JSON для хранения данных
- .m4a формат для аудио файлов
